# Собирашкин

Локальная панель Wildberries для работы с новыми заказами FBS нескольких магазинов. Интерфейс доступен по адресу http://127.0.0.1:8080/.

## Запуск на Mac

1. Установите Node.js 22 или новее. Для доступа к Связке ключей нужен Swift из Xcode или Xcode Command Line Tools (`xcode-select --install`). В папке проекта выполните `node wb-live.cjs` или `bash Start-WB-Panel.command`.
2. Откройте [панель](http://127.0.0.1:8080/). Интерфейс открывается и без VDS, но для загрузки заказов потребуется настроить подключение.
3. Скопируйте `vds.example.json` в `vds.local.json` и укажите свой `host`, `port` и `user`. Поместите SSH-ключ по пути `~/.ssh/wb-panel-hk-ed25519` или создайте ключ и добавьте его публичную часть на VDS. Проверьте SSH вручную, сверив отпечаток хоста с данными провайдера: `ssh -i ~/.ssh/wb-panel-hk-ed25519 -p PORT USER@HOST`. Если ключ защищён фразой, загрузите его в SSH-агент: `ssh-add --apple-use-keychain ~/.ssh/wb-panel-hk-ed25519`.
4. Перезапустите сервер, проверьте VDS в панели и добавьте токены в разделе «Магазины». На Mac они хранятся в Связке ключей, а не в файле. При запросе macOS разрешите доступ к записи `com.sobirashkin.wb-fbs-panel`.

## Запуск на Windows

Названия магазинов сохраняются вместе с настройками. Названия товаров и ссылки на фото кешируются отдельно по каждому магазину. На Mac кеш находится в `~/Library/Caches/WB-FBS-Panel/catalog`. Токены, заказы и файлы фотографий в этот кеш не записываются.

1. Нужен Node.js 22+, Windows PowerShell и OpenSSH. Файл Start-WB-Panel.cmd также может использовать Node.js из установленного Codex на исходном ПК.
2. Скопируйте vds.example.json в vds.local.json и задайте параметры своего VDS в Гонконге. Приватный ключ по умолчанию ожидается в ~/.ssh/wb-panel-hk-ed25519. Один раз проверьте SSH руками и подтвердите отпечаток хоста.
3. Запустите Start-WB-Panel.cmd или node wb-live.cjs. На странице «Магазины» локально добавьте свои токены.
4. Для названий и фото токен должен иметь доступ к категории «Контент». Подойдёт основной токен с обеими категориями или отдельный токен «Контент».

Токены хранятся в %LOCALAPPDATA%/WB-FBS-Panel/shops.dpapi. Файл зашифрован для текущего пользователя Windows. WB API и изображения каталога запрашиваются через SSH с обязательной проверкой гонконгского IPv4. Для курса юаня используется публичный XML Банка России. Проверка VDS на странице диагностики не отправляет токен WB.

## Контекст для следующего чата

Оператор работает с пятью магазинами одного аккаунта WB. Ассортимент почти одинаковый, товары физически собираются и пакуются общей партией. Нужна единая очередь заказов через браузер на одном ПК. Прежняя ручная панель находится в WB-FBS.html, основная версия состоит из wb-live.cjs, wb-supplies.cjs и WB-FBS-live.html.

Доступ по SSH к исходному VDS с Windows был проверен. Исходящий IPv4 определялся как HK. Пользователь подтвердил, что запрос GET /api/v3/orders/new с действующим WB-токеном возвращал заказы и что заказы появились в панели. Адрес и параметры VDS в локальном конфиге, секреты вводятся заново на своём устройстве.

Сводка показывает новые заказы по магазинам. Сборка содержит фильтр по магазинам, сортировку, мультивыбор, фотографии карточек, цену и время. Названия и фотографии сопоставляются по nmId с карточками магазина. Выбранные заказы хранятся в сессии вкладки. Раздел VDS показывает внешний адрес, геолокацию, ICMP, время TCP и SSH-проверки, доступность WB.

Целые суммы в рублях и юанях отображаются без `,00`, суммы с копейками сохраняют два знака после запятой. При наведении или клавиатурном фокусе цена открывает подсказку с суммой в юанях и её источником, а таймер показывает точную дату и время заказа по Москве. Если WB отдал только рубли или юани, вторая сумма пересчитывается приблизительно по курсу ЦБ РФ. После изменений в `WB-FBS-live.html` перезапустите локальный сервер, чтобы он перечитал файл.

«Поставки» показывает открытые и закрытые поставки WB с фильтром по магазинам. Для отправки выберите заказы на главной или в «Сборке», рассчитайте группы и подтвердите отправку нужной группы. Панель повторно проверяет новые заказы и использует совместимую открытую поставку панели за сегодня по Москве. Название новой поставки — «Поставка от <дата>». Связь со складом и параметрами совместимости хранится отдельно. Панель не закрывает поставки и не переводит их в доставку.

Название магазина вводится вручную. При переименовании повторно вводить токен не нужно.

На главной отдельно показаны «Всего», «Новые» и «На сборке», а разбивка по товарам раскрывается без дополнительных запросов. Есть только две очереди: «Новые» и «На сборке». Вторая показывает по строке на заказ, начиная с идентификатора «магазин · дата · номер WB».

На Mac стикеры скачиваются в PDF 58 × 40 мм: один заказ — одна страница, все стикеры — один многостраничный файл. В «Поставках» есть локальный Excel-шаблон IMEI с номерами заказов и пустыми текстовыми ячейками. Это не официальный файл импорта WB. IMEI можно сохранить поштучно через API, если заказ поддерживает маркировку.

Новые заказы, списки поставок, их состав и стикеры сохраняются в локальном кеше на пять минут, в том числе между перезапусками. Токены в кеше не хранятся. «Обновить заказы» и «Обновить поставки» позволяют запросить соответствующие данные сразу. Перед записью в WB панель по-прежнему перепроверяет актуальное состояние.


Тестировать запись в WB только после подключения соответствующих прав.
