# Собирашкин

Локальная панель Wildberries для работы с новыми заказами FBS нескольких магазинов. Интерфейс доступен по адресу http://127.0.0.1:8080/.

## Запуск на Windows

1. Нужен Node.js 22+, Windows PowerShell и OpenSSH. Файл Start-WB-Panel.cmd также может использовать Node.js из установленного Codex на исходном ПК.
2. Скопируйте vds.example.json в vds.local.json и задайте параметры своего VDS в Гонконге. Приватный ключ по умолчанию ожидается в ~/.ssh/wb-panel-hk-ed25519. Один раз проверьте SSH руками и подтвердите отпечаток хоста.
3. Запустите Start-WB-Panel.cmd или node wb-live.cjs. На странице «Магазины» локально добавьте свои токены.
4. Для названий и фото токен должен иметь доступ к категории «Контент». Подойдёт основной токен с обеими категориями или отдельный токен «Контент».

Токены хранятся в %LOCALAPPDATA%/WB-FBS-Panel/shops.dpapi. Файл зашифрован для текущего пользователя Windows. WB API и изображения каталога запрашиваются через SSH с обязательной проверкой гонконгского IPv4. Для курса юаня используется публичный XML Банка России. Проверка VDS на странице диагностики не отправляет токен WB.

## Контекст для следующего чата

Оператор работает с пятью магазинами одного аккаунта WB. Ассортимент почти одинаковый, товары физически собираются и пакуются общей партией. Нужна единая очередь заказов через браузер на одном ПК. Прежняя ручная панель находится в WB-FBS.html, основная версия состоит из wb-live.cjs, wb-supplies.cjs и WB-FBS-live.html.

Доступ по SSH к исходному VDS с Windows был проверен. Исходящий IPv4 определялся как HK. Пользователь подтвердил, что запрос GET /api/v3/orders/new с действующим WB-токеном возвращал заказы и что заказы появились в панели. Адрес и параметры VDS в локальном конфиге, секреты вводятся заново на своём устройстве.

Сводка показывает новые заказы по магазинам. Сборка содержит фильтр по магазинам, сортировку, мультивыбор, фотографии карточек, цену и время. Названия и фотографии сопоставляются по nmId с карточками магазина. Выбранные заказы хранятся в сессии вкладки. Раздел VDS показывает внешний адрес, геолокацию, ICMP, время TCP и SSH-проверки, доступность WB.

Целые суммы в рублях и юанях отображаются без `,00`, суммы с копейками сохраняют два знака после запятой. При наведении или клавиатурном фокусе цена открывает подсказку с суммой в юанях и её источником, а таймер показывает точную дату и время заказа по Москве. Если WB отдал только рубли или юани, вторая сумма пересчитывается приблизительно по курсу ЦБ РФ. После изменений в `WB-FBS-live.html` перезапустите локальный сервер, чтобы он перечитал файл.

Раздел «Поставки» сейчас только рассчитывает группы. Файлом wb-supplies.cjs подготовлены контракты на чтение списка, создание и добавление заказов. Запись в WB не подключена по просьбе пользователя. Когда появятся права, сначала реализовать поиск открытых поставок за текущую дату по МСК, подтверждение склада и совместимости по cargoType, crossBorderType и isB2b. Сохранять связь с подтверждённой поставкой, блокировать параллельную отправку для одного магазина, повторно сверять новые заказы и состав поставки после сбоя. WB добавляет до 100 заказов за вызов. Совместимые задания следующих партий идут в уже открытую поставку за день. Товары одного склада с несовместимыми атрибутами требуют отдельных поставок.

Для продолжения разработки на Mac начните с этого README и текущих файлов. Сервер сейчас привязан к Windows через DPAPI, путь к OpenSSH и ICMP-команду. Для запуска на Mac нужно выделить платформенный слой, использовать системный ssh и macOS Keychain. Конфиг VDS и токены вводятся на Mac отдельно. Тестировать запись в WB только после подключения соответствующих прав.
