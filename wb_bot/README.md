# Telegram-бот для заказов Wildberries

Бот работает с FBS. Статистика запрашивается из WB с первого числа текущего месяца по московскому времени и включает все полученные сборочные задания, в том числе отменённые. Список сборки включает новые задания всех подключённых магазинов и группирует одинаковые очищенные названия. Если название недоступно, бот показывает артикул.

«Статистика» показывает новые задания и задания на сборке в открытых поставках. Под сводкой две кнопки. «Количество» отправляет PNG с отдельной шкалой для каждого магазина. «Выкуплено» и «В доставке» в нём показывают текущий статус заданий, созданных в этом месяце. Заказы, уже ожидающие покупателя в пункте выдачи, в доставку не входят. Прочерк означает, что WB не вернул статусы.

«Сумма» отправляет PNG с суммой продаж за сегодня и с начала месяца в юанях, по всем магазинам и по каждому. Бот использует дату и цену `finishedPrice` из оперативного отчёта WB «Продажи», исключая строки возвратов. Для этой кнопки токену нужна категория «Статистика». По умолчанию суммы отчёта считаются рублёвыми и пересчитываются по курсу ЦБ РФ на день запроса. Если все отчёты твоих магазинов уже в юанях, задай `WB_SALES_CURRENCY=CNY` в окружении бота. Сам отчёт предварительный, данные могут появляться с задержкой.

На Ubuntu для кириллицы нужен пакет `fonts-dejavu-core`. Для установки зависимостей запусти `.venv/bin/python -m pip install -r requirements.txt` из папки `wb_bot`.

## Запуск на Windows

Из корня проекта, в PowerShell 7 с Python 3.11 или новее.

```powershell
python -m venv .\wb_bot\.venv
.\wb_bot\.venv\Scripts\python.exe -m pip install -r .\wb_bot\requirements.txt
.\wb_bot\.venv\Scripts\python.exe -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

Создай бота в @BotFather. Укажи его токен, числовой ID своего Telegram-аккаунта и сгенерированный ключ. Кнопка «Пинг» сразу отвечает «Понг», затем параллельно измеряет время до HTTP-ответов WB и `https://vk.ru/` с машины, где запущен бот. Для своей контрольной точки задай `MOSCOW_PING_URL`. Проверка сайта VK измеряет ответ веб-сервиса и не определяет географию узла. До подключения первого магазина WB может ответить HTTP 401.

```powershell
$env:TELEGRAM_BOT_TOKEN = Read-Host "Токен BotFather" -MaskInput
$env:TELEGRAM_OWNER_ID = Read-Host "Числовой Telegram ID"
$env:WB_BOT_KEY = Read-Host "Ключ Fernet" -MaskInput
$env:MOSCOW_PING_URL = Read-Host "URL московского сервера (можно оставить пустым)"
.\wb_bot\.venv\Scripts\python.exe .\wb_bot\bot.py
```

Запускай одну копию бота на токен. После запуска открой личный чат с ботом, отправь `/start` и нажми «Добавить магазин». Для чтения заказов токену нужна категория «Маркетплейс», для названий товаров — «Контент». Подойдёт токен с правами только на чтение. Повторное добавление того же магазина заменяет токен.

Бот отвечает только указанному Telegram ID в личном чате. Токен проходит через Telegram. Бот удаляет входящее сообщение перед проверкой и сохраняет токен в зашифрованном виде в `wb_bot.sqlite3`. Храни ключ Fernet отдельно от базы и используй тот же ключ при перезапуске.
